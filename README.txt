SteadyStrong — Exercise Library + realistic exercise images

INSTALL ON YOUR EXISTING GITHUB PAGES APP
1. Extract this ZIP.
2. In kstradlingrn/Workoutapp, upload index.html and SteadyStrong.html to
   the repository root, replacing the previous files. Commit the upload.
3. Wait for GitHub Pages to finish, then refresh:
   https://kstradlingrn.github.io/Workoutapp/
Both HTML files are identical and contain all built-in artwork. There is no
image folder to upload. The TXT/JSON files document the update and are optional.
This ZIP does not automatically update GitHub.

EXERCISE LIBRARY
Tap Exercise Library in the bottom navigation (third tab), then Add exercise.
Enter a name and add a video link, picture/screenshot, written instructions,
or any combination. Search, edit, replace/remove pictures, and delete work
within this section. Video links open the original website.
Entries save on the current browser/device with your existing app data.
Settings > Export backup includes custom exercise entries and their pictures.
Custom entries are saved references, not automatically added to generated
workouts. Pictures are resized up to 1600 pixels using high-quality JPEG.

EXERCISE IMAGERY
Realistic generated teaching images include 52 start/action movement pairs,
covering standing, seated, band and bodyweight variations. All 202 built-in
exercise entries include at least one realistic movement reference. The
existing equipment-specific diagrams remain where needed for exact variations.
Full generated image resolution is retained in embedded WebP quality 100.
On narrow screens, the start/action images stack for a larger view.
Image details and the generation prompt descriptions are in IMAGE_DETAILS.json.

EXISTING FEATURES RETAINED
100 strength exercises, 100 cardio options, two recovery entries, independent
strength/cardio counts, time-based workout generation, equipment/position
filters, exercise/workout alternatives, original coaching voices, muscle
search, workout history, calorie estimates, time/miles movement logs, food,
progress, and backup export. Existing storage keys are unchanged.
Continue using the same browser and site address to retain saved data.
